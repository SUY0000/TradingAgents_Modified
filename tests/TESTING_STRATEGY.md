# CCXT增强功能测试策略

## 概述
本文档描述了CCXT增强功能的测试策略，包括多时间周期支持和OKX API集成。

## 测试分类

### 1. 单元测试
测试单个函数/方法的正确性。

**测试范围：**
- `ccxt_data.py` 中的函数
- `interface.py` 中的路由逻辑
- `config.py` 中的配置处理
- 工具函数签名和参数处理

**测试重点：**
- 时间周期参数的正确处理
- 缓存键生成（包含时间周期）
- 技术指标计算（不同时间周期）
- 错误处理和边界情况

### 2. 集成测试
测试组件间的集成和数据流。

**测试范围：**
- CCXT供应商与路由系统的集成
- 多供应商回退机制
- 缓存系统与文件I/O
- 配置系统的正确传播

**测试重点：**
- 完整的数据获取流程
- 供应商回退链
- 配置覆盖和优先级
- 缓存命中/未命中场景

### 3. 兼容性测试
确保向后兼容性。

**测试范围：**
- 现有API的无破坏性更改
- 默认行为的一致性
- 配置参数的向后兼容

**测试重点：**
- 现有代码无需修改即可工作
- 默认时间周期（1d）与现有行为一致
- 新增参数为可选参数（**kwargs）

### 4. 性能测试
测试缓存效率和API调用频率。

**测试范围：**
- 缓存性能（命中率、加载时间）
- API调用频率限制
- 内存使用情况
- 多时间周期的缓存隔离

**测试重点：**
- 相同数据不应重复调用API
- 不同时间周期应有独立的缓存
- 缓存文件大小和清理机制

## 测试工具和夹具

### Mock CCXT Exchange
模拟CCXT交易所API，避免真实API调用。

### 测试数据生成器
生成不同时间周期的测试数据。

### 配置管理器
测试环境下的配置管理。

## 测试数据管理

### 静态测试数据
预定义的测试数据集，用于单元测试。

### 动态测试数据
运行时生成的模拟数据，用于集成测试。

### 缓存测试数据
模拟缓存文件，测试缓存逻辑。

## 测试覆盖率目标

- 语句覆盖率：>= 80%
- 分支覆盖率：>= 75%
- 函数覆盖率：>= 85%

## 测试执行

### 本地开发
```bash
# 运行所有测试
pytest tests/

# 运行单元测试
pytest tests/unit/ -m unit

# 运行集成测试  
pytest tests/integration/ -m integration

# 运行性能测试
pytest tests/performance/ -m performance

# 生成覆盖率报告
pytest --cov=tradingagents.dataflows tests/
```

### CI/CD集成
测试应集成到项目的CI/CD流程中。

## 测试环境要求

- Python 3.10+
- 测试依赖：pytest, pytest-mock, pytest-cov
- 无外部API依赖（使用mock）
- 临时文件目录用于缓存测试

## 风险缓解

1. **API变化**：使用mock避免依赖外部API
2. **测试数据过时**：定期更新测试数据生成器
3. **测试性能**：性能测试单独执行，不阻塞开发
4. **环境差异**：使用固定随机种子确保可重复性
